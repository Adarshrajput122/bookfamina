# 📚 BOOKFAMINA

**BOOKFAMINA** is an intuitive and modern online platform designed to simplify book discovery, management, and recommendations. Built using **React** and powered by **Vite**, the project showcases a clean UI, responsive design, and scalable frontend architecture — perfect for book lovers and learners.

---

## 🚀 Features

- 🔍 **Search Functionality** – Instantly search for books by title or author.  
- 📖 **Detailed Book View** – See in-depth details like synopsis, genre, and ratings.  
- 🧠 **Personal Library** – Add, remove, and manage your favorite books.  
- 💡 **Smart Recommendations** – Get book suggestions based on your interests.  
- 🌙 **Dark Mode Support** – Seamless toggle between light and dark themes.  
- ⚡ **Blazing Fast** – Powered by Vite for fast development and performance.
